# Confluence Elastic Search - 기술 자료 집대본

## 🎯 프로젝트 개요

Confluence Data Center 환경에서 동작하는 Multi-SPA (Multiple Single Page Application) 아키텍처 기반의 Elastic Search 플러그인 프로젝트입니다.

## 🏗️ 전체 아키텍처

### 1. 기술 스택

#### 1.1 백엔드 (Java)
```
Spring Framework 5.x
├── OSGi 컨테이너 (Apache Felix)
├── Confluence 8.5.4
├── REST API (JAX-RS)
├── Struts2 (MVC)
└── Velocity Templates (뷰 렌더링)
```

#### 1.2 프론트엔드 (JavaScript/TypeScript)
```
SvelteKit 5.x (Svelte 5)
├── Vite 7.x (번들러)
├── TypeScript 5.x (타입 시스템)
├── Tailwind CSS 4.x (스타일링)
├── pnpm (패키지 매니저)
└── Paraglide (국제화)
```

### 2. 프로젝트 구조

## 📡 API 통합

### 1. REST API 설계
```java
@Path("/myplugin")
public class ElasticSearchResource {
  
  // 검색 API
  @POST
  @Path("/search")
  @Produces(MediaType.APPLICATION_JSON)
  public SearchResponse search(SearchRequest request) {
    return searchService.search(request);
  }
  
  // 자동완성 API
  @GET
  @Path("/suggestions") 
  @Produces(MediaType.APPLICATION_JSON)
  public List<String> getSuggestions(@QueryParam("q") String query) {
    return searchService.getSuggestions(query);
  }
  
  // 관리자 API
  @GET
  @Path("/admin/index")
  @RolesAllowed("administrators")
  public AdminDashboardData getDashboard() {
    return adminService.getDashboardData();
  }
}
```

### 2. 프론트엔드 API 클라이언트
```typescript
// 공유 API 클라이언트
export class ConfluenceApiClient {
  private baseUrl = '/rest/myplugin/1.0';
  
  async search(request: SearchRequest): Promise<SearchResponse> {
    const response = await fetch(`${this.baseUrl}/search`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-Atlassian-Token': 'no-check'
      },
      body: JSON.stringify(request)
    });
    return response.json();
  }
}
```

## 🔧 운영 및 모니터링

### 1. 로그 및 모니터링
```java
// 구조화된 로깅
@Component
@Slf4j
public class SearchService {
  
  public SearchResponse search(SearchRequest request) {
    log.info("Search request: {}", request);
    
    try {
      SearchResponse response = performSearch(request);
      log.info("Search completed: {} results in {}ms", 
          response.getTotalCount(), response.getExecutionTime());
      return response;
    } catch (Exception e) {
      log.error("Search failed for request: {}", request, e);
      throw new SearchException("Search operation failed", e);
    }
  }
}
```
